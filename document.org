* Windows 疑难杂症
** WIN + v 键打不开剪贴板窗口

注册表选项没有开

#+begin_src bat
reg add "HKLM\SOFTWARE\Microsoft\Clipboard" ^
/v IsCloudAndHistoryFeatureAvailable ^
/t REG_DWORD /d 1 /f
#+end_src

** 删除文件显示有其它文件打开

- WIN + r 输入 *resmon*
  - 选择 *CPU* 选项卡 并点击关联句柄
    - 搜索要删除的文件并被所有搜索出来的举报全部杀掉

** 控制面板里面找不到散热选项

Windows Server 版本或某些电源计划下，这个选项会被隐藏

#+begin_src sh
powercfg -attributes SUB_PROCESSOR 94D3A615-A899-4AC5-AE2B-E4D8F634367F -ATTRIB_HIDE
#+end_src

** 关闭Windows Update服务

gpedit.msc -> 计算机配置 -> 管理模板 -> Windows 组件 -> Windows 更新，
设置 *配置自动更新* 为禁用

彻底一点, 参考仓库链接: https://github.com/tsgrgo/windows-update-disabler/tree/main

** 缺少 VCRUNTIME-xxx.dll

就是缺少vs相关的.dll而已, 很多软件不会自带, 需要去微软官网下载一个
链接: https://learn.microsoft.com/zh-cn/cpp/windows/latest-supported-vc-redist?view=msvc-170#latest-supported-redistributable-version

** 文件访问权限
- 获取文件所有权 =takeown /F "C:\path\to\dir" /R /D Y >nul 2>&1=
- 设置访问权限是当前用户 =icacls "C:\path\to\dir" /grant "%USERNAME%":F /T /C=

* git 疑难杂症
** 文件被更改了 但是git不显示变动

很有可能是 *ignorecase* 选项的问题, 注意全局配置和当前目录的 *.git* 目录的 *conf* 文件配置.
勇士很有可能还有很多文件被打上了标记, 需要重新更新git索引.

设置 ignorecase 选项
#+begin_src sh
git config --global --unset core.ignoreStat
git config --local --unset core.ignoreStat
#+end_src

更新索引
#+begin_src sh
git ls-files -v | \
awk '$1 ~ /^[a-z]/ {print substr($0,3)}' | \
git update-index --no-assume-unchanged --stdin
#+end_src
